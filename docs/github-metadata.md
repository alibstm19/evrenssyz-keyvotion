## Uzun tanıtım (Release / paylaşım metni)

> **Keyvotion Console — EVREN SSYZ için yapay zekâ ajan ekibi konsolu.**
>
> Tek bir modeli konuşturmak yerine onu bir ekibin parçası gibi çalıştırın:
> Lider hedefi verir, mimar planı böler, yazılımcı üretir, test yazılımcısı kapıyı
> işletir. Yedi rol, tek pano, ortak hafıza ve ölçülebilir kalite.
>
> Konsolun ana dayanağı **EVRENSSYZ**'dir. Uygulamanın kullandığı **API'ler ve API
> jetonları EVREN SSYZ adresinden alınır**; kendi anahtarınızı oradan alıp
> bağlarsınız. Veri ve sırlar makinenizde kalır: pano, raporlar ve ayarlar proje
> klasöründe, parolalar Windows kasasında (DPAPI) şifreli.
>
> Öne çıkanlar: 23 ekran, 124 hazır bağlantı (64 entegrasyon + 60 MCP sunucusu),
> telefondan uzaktan kontrol, tek tuşla tanılama, hareket azaltma, OAuth2/API
> anahtarı/MCP kurulumu, Votion sesli asistan ve 574 otomatik test.
>
> Windows 10/11. Tek çalışma zamanı bağımlılığı Electron. Telemetri yok.
